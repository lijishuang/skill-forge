# Skill 工坊 · 浏览器插件

上传 / 保存 SKILL.md → 自动生成适配的操作界面 → 填参数调用 LLM 执行。
Chrome / Edge 等基于 Chromium 的浏览器均可安装（Manifest V3）。

## 安装（开发者模式加载，无需上架）

> **不想装插件？** 使用工作区根目录的 `skill-forge-standalone.html` 独立版：单文件、双击浏览器打开即用（数据存 localStorage，无右键菜单/技能库弹窗外的插件能力差异，核心功能完全一致）。

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `skill-forge-extension` 文件夹
4. 工具栏出现 ⚒ 图标即安装成功（建议钉到工具栏）

## 使用

### 基本流程
1. 点击图标 → 「打开工作台」
2. 首次使用：展开「模型配置」，填 OpenAI 兼容接口的 Base URL、Key、模型名
   （例：`https://api.deepseek.com/v1` + `deepseek-chat`；本地 Ollama 填 `http://127.0.0.1:11434/v1`）
3. 上传 SKILL.md（文件 / 文件夹 / 粘贴，或点「试用示例」）
4. 点「⚡ 生成界面」三种方式任选：
   - 自动解析占位符（免 Key）
   - AI 智能设计界面（每个 Skill 生成不同表单）
   - 手动补字段
5. 填写表单 → 「▶ 用 LLM 执行此 Skill」→ 流式输出结果，可复制 / 下载 .md

### 生成界面 → 单独打开为 HTML 页面 ⭐
- 生成界面后，卡片下方有两个按钮：
  - **🌐 新标签页打开此界面**：把当前界面变成一个独立的工具页在新标签页打开（插件内走扩展页面 + 沙箱，界面、配置、执行能力完整保留，可直接执行）
  - **⬇ 保存为 .html**：下载一个单文件 HTML 工具页，双击就能用、也能发给别人（出于安全不包含 API Key，首次使用填一次即可，页面会自己记住）
- 执行结果如果包含 HTML（完整文档、```html 代码块或明显页面片段），会自动渲染成**页面预览**，可切「源码」查看，并可「🌐 单独打开为 HTML 页面」（沙箱内真实渲染，脚本可执行）或下载 .html

### 我的页面 ⭐
把生成的页面保存进插件，下次**点击即直接打开使用**：
- 三个保存入口：① 生成界面后点「📥 存入我的页面」→ 保存为**工具页**（表单 + 执行能力完整保留，Key 不入库，打开时自动读取当前配置）；② 执行结果检测到 HTML 后点「📥 存入我的页面」→ 保存为**网页**；③ 历史查看器里同样可存
- 工作台「🧩 我的页面」卡片：点击条目直接打开；**双击名称可重命名**；✕ 删除；同名同类型保存时自动覆盖更新
- **插件弹窗也列出全部页面**，点一下新标签页直达，不用进工作台
- 工具页上限 100 个，全部存于插件本地（chrome.storage.local）

### 生成历史
- 每次执行成功自动保存（保留最近 50 条），显示所用 Skill、类型徽标（HTML/文本）和时间
- 点击记录弹出结果查看器：HTML 记录直接渲染成页面，文本记录渲染为 Markdown
- 支持「🔄 重新生成」：回填当时的 Skill、界面与参数，改改就能重跑；也可删除单条

### 技能库
- 上传解析后点「💾 存入技能库」，永久保存在插件本地（chrome.storage.local）
- 下次直接从工作台左侧或插件弹窗一键载入

### 技能压缩包（.zip）
- 直接拖入或选择 `.zip`，自动在浏览器本地解压（零依赖，支持 store/deflate 压缩）
- **单技能包**：压缩包内含一个 SKILL.md（可在子目录中），SKILL.md 及其 references/、scripts/ 等附带文件一起载入
- **多技能包**：压缩包内含多个技能目录（如整个技能仓库），自动批量导入技能库并加载第一个
- 过大（>512KB）或二进制类型的附带文件自动跳过不内联

### 网页右键（杀手级功能）
- 在任意网页**选中 SKILL.md 全文** → 右键「📥 存入 Skill 工坊」→ 打开工作台确认保存
- 在任意网页**选中内容** → 右键「▶ 用 Skill 工坊执行选中内容」→ 打开工作台选一个 Skill，选中内容自动填入表单执行

### 中英文双语 🌐
- 每个页面（工作台 / 生成的工具页 / 页面预览器 / 插件弹窗）右上角都有「中文 / EN」切换器
- 选择会记住：插件内所有页面共享；导出的单文件 HTML 也内置双语能力，收件人可自己切换
- 默认语言跟随浏览器；界面全部翻译，**Skill 自己的字段名、提示和 LLM 输出内容保持原样**（属于内容而非界面）

## 权限说明
- `contextMenus`：提供右键菜单
- `storage`：本地保存技能库与配置（不经过任何服务器）
- `host_permissions (http/https)`：工作台页面需要直连你配置的 LLM API

API Key 仅保存在本机浏览器存储中，请求由本机直接发向你配置的 API 地址。

## 文件结构
```
skill-forge-extension/
├── manifest.json      # MV3 配置（含 sandbox 沙箱页声明）
├── background.js      # 右键菜单 + 打开工作台
├── popup.html/js      # 工具栏弹窗（技能库 + 我的页面 + 快捷入口）
├── app.html/js        # 工作台（核心界面）
├── tool.html/css/js   # 独立工具页（「新标签页打开此界面」+ 导出单文件共用）
├── doc.html/js        # 结果页面预览器（沙箱真实渲染）
├── sandbox.html       # 沙箱页（执行生成页面里的脚本）
└── icons/             # 图标
```
